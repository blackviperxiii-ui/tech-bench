## Acceptance criteria
- **AC1 (E1):** In `IdSettingsForm`, mask the IntelliDealer subscription key field the same way the OAuth secret is masked (`UseSystemPasswordChar`), and give it the same show/hide behavior if the secret has one.
- **AC2 (E2):** KB "Open file" (`SearchControl.OpenSel`) refuses executable and script types. The blocklist covers at least .exe .com .bat .cmd .scr .pif .msi .msp .ps1 .psm1 .vbs .vbe .js .jse .wsf .wsh .hta .cpl .reg .lnk .jar. Matching is case-insensitive and catches double extensions such as `x.pdf.exe`. A blocked file gets a clear message. Documents, images and other types open as before.
- **AC3 (D1):** Unit-history import (`ShopSync.ImportHistory`) dedupes on file content (hash, or size+mtime+hash), not on the name alone. A file with the same name but different contents is imported or updated. An identical file is still skipped.
- **AC4 (D2):** Work-order files (`WorkOrderStore`) are written atomically: write a temp file in the same folder, then replace the target and keep a `.bak` of the previous version. A crash mid-write cannot leave a truncated work order.
- **AC5 (B2):** INLINE 7 "Clear previous" (`Rp1210.ClearPreviousFaults`) reports the real outcome. If any send fails, it shows failure with counts, not success. Source: PR #10 review W2.
- **AC6 (C5):** The `app.manifest` assemblyIdentity version is `1.2.7.0` and matches `AppVersion`.
- **AC7:** Each of AC1–AC6 has a self-test in the existing `SelfTest` harness (`test.bat` / CI). All existing tests still pass, and CI is green on the PR head.
