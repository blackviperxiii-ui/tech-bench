# Tech Bench v1.2.34: Rearch stage 12, job strip text out of the shell

## Problem
`ShellForm` built the job strip's text by hand: the window title, the job tag (open work order, else model and serial), the sync chip, and the work-order pick list with its selected row. None of it had a test.

## Change
- `src/Features/WorkOrders/JobStrip.cs` (core): pure `WindowTitle`, `JobTag`, `SyncChip`, `PickItems` and `Picked`, plus the `NoWorkOrder` and `SyncIdle` strings.
- `ShellForm.Title`, `SyncJob`, `ApplySyncStatus`, `FillWoPick` and `PickWoFromStrip` call them. Colours, layout and the `_filling` guard stay in the shell.
- New SelfTest case `job strip text` (Order 98, `tests/SelfTest.JobStrip.cs`). `ExpectedCaseCount` 49 -> 50. Lockstep version bump.

## Behaviour
Unchanged: the same title, tag, chip text, pick-list rows, case-insensitive reselect, and stale-row ignore.

## Non-goals
- Work-order storage, shop sync, the updater, INLINE 7, layout.
