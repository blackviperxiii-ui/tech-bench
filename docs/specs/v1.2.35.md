# Tech Bench v1.2.35: Rearch stage 13, shortcuts and job hand-offs out of the shell

## Problem
`ShellForm` decided its keyboard shortcuts inline in the KeyDown handler, and built three job hand-offs by hand: the Search this job query, the customer shown at launch, and the DTC csv path it publishes after INLINE 7 saves a session. None had a test.

## Change
- `src/Core/Shell/ShellShortcuts.cs` (core): pure `ShellShortcuts.For(control, keyCode)` returning `FocusSearch` (Ctrl+F or F3), `AddCode` (Ctrl+N), `CheatSheet` (F1) or `None`, in the same order as before.
- `JobStrip` gains `SearchQuery`, `StartupCustomer` and `DtcCsvFor`.
- `ShellForm` KeyDown switches on `ShellShortcuts.For`; the constructor calls the three `JobStrip` helpers. `ShopSync.PublishHistory` is still only called, unchanged.
- New SelfTest case `shell shortcuts and job hand-offs` (Order 99, `tests/SelfTest.Shortcuts.cs`). `ExpectedCaseCount` 50 -> 51. Lockstep version bump.

## Behaviour
Unchanged: the same keys (F3 and F1 with any modifier, Ctrl+F, Ctrl+N), the same query, the same launch customer precedence, and the same csv name.

## Non-goals
- Shop sync, the updater, INLINE 7 session writing, layout.
