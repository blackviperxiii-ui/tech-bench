# Tech Bench v1.2.33: Rearch stage 11, window placement out of the shell

## Problem
`ShellForm` decided by hand whether the saved window bounds are restored (at least the minimum size and on some screen's working area) and copied the bounds back into `settings.json` on close. Neither rule had a test.

## Change
- `src/Core/Settings/WindowPlacement.cs` (core): pure `SavedBounds(settings, minimum, workingAreas)` and `Capture(settings, maximized, normalBounds)`.
- `ShellForm.ApplyWindow` passes the screens' working areas in; `PersistSettings` calls `Capture`. `OnAnyScreen` is gone. The job-strip clearing in `PersistSettings` is unchanged.
- New SelfTest case `window placement` (Order 97, `tests/SelfTest.Window.cs`). `ExpectedCaseCount` 48 -> 49. Lockstep version bump.

## Behaviour
Unchanged: the same minimum-size and on-screen rules, maximized restore, `FitToWorkingArea`, and the same fields saved on close.

## Non-goals
- Settings file format, the settings write gate, layout, updater, INLINE 7.
