# Tech Bench v1.2.21: BusSnapshot IncludesBusLists for UI Refresh

Fixes a one-cycle blank of the INLINE 7 Bus PGN/SA list boxes when the 800 ms refresh boundary falls between `OnUiTick` and `Refresh`.

## Scope
- `BusSnapshot.IncludesBusLists` set when `Snapshot(true)` fills PGN/SA rows.
- `Inline7Control.Refresh` gates `Repopulate` on that flag (not a second clock read).
- Lockstep version bump to 1.2.21.

## Non-goals
- No clear-code path changes, no confirm-dialog changes, no DEF/SCR reset, no calibration writes.
- No IdGateway redirect changes (separate held finding; blocked on #61).
