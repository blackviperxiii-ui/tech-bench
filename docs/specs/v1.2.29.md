# Tech Bench v1.2.29: Rearch stage 8, Adapters page out of the shell

## Problem
`ShellForm` built the Adapters page itself (`BuildAdaptersPanel`) and formatted its text (`DescribeAdapters`), mixing a feature page and RP1210 reporting into the shell. The text read the PC directly, so no test could pin it.

## Change
- `src/Features/Adapters/AdapterSummary.cs` (core): pure `AdapterSummary.Text(iniPath, hostIs32Bit, apis)`, the same wording as before.
- `src/Features/Adapters/AdaptersPage.cs` (app): the page panel with Rescan, calling `AdapterSummary.Text` with the PC's real INI path, process bitness and installed adapters.
- `ShellForm` registers `new AdaptersPage()` in the stage 7 page map and drops `BuildAdaptersPanel` / `DescribeAdapters`.
- New SelfTest case `adapters page summary` (Order 96): literal text for no adapters, a null list, a 64-bit host, and one INLINE 7; plus a guard that the shell hosts `AdaptersPage`. `ExpectedCaseCount` 44 -> 45. Lockstep version bump.

## Behaviour
Unchanged: same page layout, text, and Rescan.

## Non-goals
- Search, Work orders and INLINE 7 pages, Safety files, updater.
